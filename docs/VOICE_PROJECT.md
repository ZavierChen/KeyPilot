# KeyPilot Voice · 个性化语音子项目

[项目首页](../README.md) · [语音包规范与导入](VOICE_PACKS.md) · [研究工具](VOICE_LAB.md) · [声音迭代历史](VERSION_HISTORY.md)

**让助手用自己选择的声音说话：用少量参考样本起步，按硬件和使用频率选择本地合成、一次制作后 CPU 长期使用，或云端 API。**

个性化语音是 KeyPilot 的独立技术方向，目前与桌面助手在同一仓库维护，已有多引擎适配、训练研究工具、播放调度、语音包规范和本地导入入口。它可以继续发展为独立的声音制作与部署工具，供其他应用集成；当前尚未另行发布独立安装程序或通用 SDK。

## 三条路线，按自己的条件选择

| 路线 | 适合的情况 | 如何实现 | 成本与体验取舍 |
| --- | --- | --- | --- |
| **较强 GPU：短样本直接本地克隆** | 有足够显卡算力与显存，希望声音留在本地 | 下载支持参考音的预训练模型，提供短参考录音及所需文本，本地生成新语音；项目已有 Qwen3-TTS 零样本适配 | 无需为这个声音专门训练，也无需按次购买云端合成额度；仍消耗本机资源。项目早期使用中冷加载与逐句响应较慢，实际等待取决于模型、硬件与预热状态 |
| **CPU 长期使用：云端辅助制作，本地部署** | GPU 不适合常驻语音模型，希望一次制作后持续低成本使用 | 少量自备参考音 → 云端教师语料辅助扩充 → 微调可部署的本地模型 → 导出 ONNX INT8 → CPU 合成；项目已探索 ZipVoice v1–v7 | 作者估计约 **3 美元/次制作**，完整成本尚待核算；制作完成后，日常朗读不再逐次调用云端。历史 CPU 实验达到可用于日常助手的速度取舍，需在目标电脑试听与测量 |
| **云端 API：按需选择速度与质量** | 更重视所选服务的声音质量、首音响应，接受联网与持续服务费用 | 配置支持的云端音色与合成服务，返回音频并播放；项目已有火山引擎流式 TTS 适配 | 不必在使用者电脑持续运行大型语音模型；通常消耗额度或按量付费，延迟与质量取决于服务、网络及配置，不保证所有云端方案都更快 |

这三条路径提供不同的成本结构：**本地 GPU 省去个性化训练步骤；CPU 路线把制作投入放在前期，之后长期本地使用；云端 API 将算力和合成交给服务方。** 用户可以选择模型和声音，不必因为更换问答服务就重做整套语音配置。

短参考音驱动克隆来自上游模型能力：[Qwen3-TTS Base 官方说明](https://github.com/QwenLM/Qwen3-TTS)提供少量参考音克隆；[ZipVoice / sherpa-onnx](https://k2-fsa.github.io/sherpa/onnx/tts/zipvoice.html)也支持使用参考录音和对应文本离线合成。项目的贡献是将这些路线接入桌面应用，并处理训练实验、部署、导入和实际播放体验。

CPU 本身不强制要求云端训练：公开 ZipVoice 也可以直接进行零样本合成。表中的云端辅助路线，是本项目为改善个人音色而探索的制作方案，用户仍可先试未经个人微调的公开模型。少样本不代表任意一段低质量录音都能得到稳定音色；录音质量、文本一致性和独立试听仍是关键。

## 一次制作，本地长期使用

CPU 路线把定制工作放在前期：用云端模型帮助生成教师语料，再训练可部署的本地模型，最终将自己的推理资源导入电脑。迁移的是训练得到的本地能力，并非导出云服务商的私有模型参数。训练算力可以来自制作方本机 GPU 或另行租用；CPU 是交付后的推理目标，不代表所有训练也在用户 CPU 上完成。

**约 3 美元是作者提供的单次制作成本估计，不是固定售价或每次朗读费用。** 当前没有逐项账单证明它覆盖全部教师合成、训练算力、失败重试和交付成本；正式提供制作服务前会核算。这条路线的长期价值是让制作完成的音色持续在本机发声，避免为每次使用重复购买云端合成。

历史实验记录了一个具体例子：v4 的单句 CPU 4 步合成约用 1.57 秒生成 4.64 秒音频；后续 8 步候选在听感和速度间作取舍。该数字是特定历史机器与配置下的合成耗时，不是用户说完到助手开口的端到端延迟，也不代表最新默认音色或所有电脑。完整条件与选择过程见[历史记录](VERSION_HISTORY.md#历史指标可支持的结论)。

## 已实现什么

- **多种声音来源接入**：系统声音、联网声音、Qwen 本地 GPU、ZipVoice CPU、RVC 及云端流式 TTS 的适配与研究代码。
- **个人音色实验与部署**：参考音处理、教师语料、训练辅助、模型选择、ONNX INT8 部署，以及中英文分流的历史过程。
- **持续使用的播放体验**：可打断朗读、结果编辑重读、分段预取、按需加载与释放、常驻预热、长度和语速设置。
- **别人能复现的导入流程**：资源相对路径、纯数据清单、依赖与真实模型加载校验，以及本机导入和试听。

当前标准导入器覆盖 **ZipVoice CPU 语音包 v1**；GPU 和云端路径需要单独配置，并非已经在同一向导内一键完成。声音质量不能由文件校验或导入成功代替，应使用没有参加训练的文本做独立试听。
