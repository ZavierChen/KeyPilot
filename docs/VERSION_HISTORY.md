# 版本与实验迭代历史

本页是依据历史任务、版本归档和实验报告整理的**技术迭代摘要**，不是原始聊天备份。语音包仅在作者本机使用；当前项目只分发实现代码、接口规范和空白配置模板，不上传声音包、录音、合成音频、训练数据、模型权重、凭据或私人授权材料。下文提及云端语音是历史路线记录，不表示本次分发会上传或附带任何声音资源。

项目存在两条不同编号线：`KeyPilot v0.x` 是应用版本，语音 `v1–v7` 是模型候选/实验编号。训练步数 `400` 与推理步数 `4/8/16` 也不相同。以下按实际证据保留编号，不把实验目录虚构成 Git 标签或正式公开 release。聊天时间按 UTC 归日；实验报告保留其原标注日期，跨时区可能相差一天。证据编号对应 [来源索引](HISTORY_SOURCES.md)。

## 关键纠错记录

- **明确区分模型与应用**：规则能够执行并不能证明 LLM 接通；模型返回合法 JSON 也不能证明实际执行成功。本次门户因此把 `not_executed` 写入探测结果。
- **明确区分训练与推理**：Qwen/ZipVoice 零样本参考音方案没有因此获得专用训练；RVC 权重不能装入 ZipVoice。CPU 原生微调从 v1–v4 才逐步形成独立路线。
- **不以新版本自动替代旧版**：v4-500 指标回退，没有替代 v4-400；v5 在 4 步下不稳，保留 v4；v6 英文客观指标改善但听感不佳，英文继续用 v5，直到 v7 定向修复。
- **区分恢复与根治**：音色改名、重启、恢复设置和目录缓存曾恢复界面，但 9 月 9 日才以真实启动进程的路径证据定位重定向。验证覆盖桌面连续冷启动，没有声称做过整机重启。
- **区分局部与端到端性能**：RVC 200 毫秒块转换、TTS 整句生成、音频首包、播放器首声与用户说完到回复是不同指标。历史数据不能混算，更不能直接保证另一台电脑上的速度。

## 历史指标可支持的结论

v4 报告的单句 CPU 4 步结果是约 1.57 秒生成 4.64 秒音频；v5 报告同类对照显示 8 步更自然但接近实时速度；v6 的盲听与部分相似度指标出现分歧。这些支持“同时测速度、清晰度和听感，并保留旧候选”的工程决策，不足以证明普遍最优。

v7 的目标英文句参与过训练，不能用该句的改善证明未见文本泛化。历史材料尚未构成多说话人、多随机种子、足量独立听众的完整研究验证。测试通过数量也随测试范围变化，只作为当时开发记录，不作为跨版本性能评分。复现实验方法见 [测试与复现指南](TESTING.md)。

公开项目保留这段迭代过程和实现方法，私人声音资源继续留在本机。后续版本应同时记录应用提交、模型/配置版本、数据划分与评测条件，避免再次让同一显示编号代表不同实际内容。
