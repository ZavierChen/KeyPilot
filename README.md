# KeyPilot · 可复现的本地语音助手

KeyPilot 起初是为了替代 Copilot 键原来的用途，随后朝着“做一个 Windows 版 Siri”的目标发展成桌面语音助手。它把按键唤起、文字与听写输入、日常电脑操作、模型问答和语音回复放在同一个应用里。**日常使用成本低：常用操作由本机规则完成，需要语言理解时可以接本地模型，基础使用无需购买云端 API 额度。**

[公开源码](https://github.com/ZavierChen/KeyPilot) · [下载发布包](https://github.com/ZavierChen/KeyPilot/releases) · [Windows 自动验证](https://github.com/ZavierChen/KeyPilot/actions/workflows/test.yml)

## 为什么制作

作者的电脑带有 Copilot 键，但当时按下去只打开搜索，没有提供想要的助手入口。作者并没有实际用过 Copilot，也不清楚这个按键为何表现如此。

最初的想法因此很具体：**把这个按键变成有用的入口，再做一个 Windows 版 Siri。** 先让它打开自己选择的应用或语音入口，再让助手能够直接帮用户操作电脑：说一句就能打开应用、调音量或查找设置，并得到语音回复。

项目追求的是接近 Siri 的系统助手体验：**随手唤起 → 说出需求 → 完成具体操作 → 语音反馈**。重点在于这条流程是否自然、连贯，能否让使用者少找菜单、少切换窗口，直接完成日常事情。

在实际使用中，需求逐渐具体起来：日常操作应当响应快，也不必每次都新建一段云端聊天；模型与声音则希望能够按自己的需要选择。

因此，KeyPilot 逐步形成了“规则优先、本地模型补充理解、程序执行 Skill、复杂需求按配置转接”的结构。之后的迭代围绕实际使用展开：补齐时钟与网页功能，改善问答来源，减少模型空闲占用，再加入可选音色、语音调度和稳定启动。完整过程见 [项目动机、功能与演进](docs/PROJECT_OVERVIEW.md)。

## 功能简介

| 功能 | 可以做什么 |
| --- | --- |
| 日常电脑操作 | 打开应用、桌面文件和文件夹；调音量、亮度；打开设置页或填写设置搜索词 |
| 网站与快捷映射 | 打开网址或搜索；自定义“学校网站”“学习资料”等关键词与网址/本机路径的对应关系 |
| 时间助手 | 世界时间、倒计时、闹钟、提醒、任务列表与铃声；到点提醒需要后台计时进程运行 |
| 问答与页面读取 | 可选本地问答、Google AI 页面读取、Marvis 转接、兼容 API 问答；支持读取当前浏览器页面 |
| 对话与朗读 | Windows 听写、有限的当天上下文；结果编辑、复制、重读，剪贴板朗读及听写打断播报 |
| 声音设置 | 系统/联网声音、自定义本地语音包；回复长度三档、语速微调、按需加载或预热常驻 |
| Copilot 键入口 | 主动启动按键监听后，单击打开/最小化助手、双击开始/取消听写；不自动接管键盘 |
| 模型与声音扩展 | 本地模型门户、模型发现、只读路由测试、契约导出、陌生模型接入 Skill、语音包校验与本地导入 |

基础文字与规则操作无需大模型。听写依赖 Windows；模型服务、联网功能和自定义音色需分别配置。详细入口、示例与使用条件见 [完整功能说明](docs/PROJECT_OVERVIEW.md#当前功能)。

## 亮点与优势

- **基础功能免费使用，日常成本低。** 打开应用、调音量和亮度、查找设置、时间任务等可由本机规则处理；搭配本地模型与本地声音，也无需按次购买云端推理或合成额度。付费问答与外部代理按需启用。
- **模型接入可以逐步检查。** 门户提供模型发现、动作契约导出、响应校验和只读探测，让新模型先展示拟执行的 Skill 与参数，再进入实际使用。
- **回答、操作与声音分别配置。** 更换问答服务不必同时更换电脑操作或声音；本地模型只在已注册的操作范围内提出请求。
- **个性化声音可在自己的电脑重建。** 语音包使用纯数据清单和相对路径，运行时由本机选择；公开格式与导入方法，私人录音、训练数据和权重保持本地。
- **交互细节来自实际迭代。** 听写打断、结果编辑重读、分段预取、按需释放和常驻预热，围绕等待、朗读与资源占用提供具体控制。

这里的低成本指已有电脑上的持续服务费用；本地推理仍使用硬件、电力和存储。联网不一定产生付费模型调用，本地模型的 HTTP API 也不等于收费云端 API。功能与成本范围见[成本说明](docs/DIFFERENTIATION.md#1-低持续成本常用功能无需付费云端-api)。

项目的创新价值主要在 Windows 日常场景的系统整合、接入流程与可复现交付。同类产品已具备部分相似能力，当前尚无同条件实验支持“行业首创”或性能领先；官方资料对照、具体差异和后续验证方法见 [亮点、痛点与同类方案对比](docs/DIFFERENTIATION.md)。

## 发展方向与前景

长期目标是让不同品牌、小厂整机和自配 Windows 电脑，都能低成本获得接近系统原生的语音助手体验。**近期重点是把项目做成普通用户能够独立安装、配置和持续使用的成熟 App。**

- **降低部署门槛**：安装后即可使用基础功能，由应用管理运行环境，无需用户手动配置 Python 或命令行。
- **一键选择模型**：根据硬件提供经过验证的本地模型选项，管理下载与启动；也能通过向导选择 API 服务和模型。
- **英文版与中英切换**：补齐英文界面、常用命令、听写与朗读，验证英文 Windows 环境；优先复用模型已有的英文能力，按测试结果决定是否需要微调。
- **短样本声音定制**：显卡足够时使用本地模型直接合成；另探索云端教师语料辅助制作，再训练、导出为本地声音，供后续长期使用。约 **3 美元/次**是作者的初步成本目标，尚未核算，也不是已公布售价。
- **探索厂商合作**：未来可与整机厂商、装机商或模型提供方共同完成预装、适配和服务支持，让更多用户获得完整体验。

## 快速启动（Windows 10/11，64 位 Python 3.12）

在项目根目录运行 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
.\.venv\Scripts\python.exe scripts/keypilot.py gui
```

也可以完成安装后双击 `run.cmd`。**启动应用不需要先安装大模型、申请 API Key 或准备私人音色。** 基础规则操作可以直接使用；自然语言模型理解需另接模型服务。

复现版默认关闭自动联网问答、复杂代理、语音自动执行和自动语音回复；手动试听和朗读仍可使用。配置、缓存与语音包保存在 `%LOCALAPPDATA%\KeyPilot-Repro`，不会复用现用版 `KeyPilot` 数据。可用绝对路径环境变量 `KEYPILOT_DATA_DIR` 指定实验目录。

```powershell
.\.venv\Scripts\python.exe scripts/keypilot.py doctor
.\.venv\Scripts\python.exe scripts/keypilot.py models --help
.\.venv\Scripts\python.exe scripts/keypilot.py voices --help
.\.venv\Scripts\python.exe -m pytest -q
```

## 项目范围

- `desktop/`：完整桌面端源码、注册操作、系统语音脚本与测试；只支持 Windows。
- `src/voice_assistant/`：独立语音研究工具；不是启动桌面应用的前置服务。
- `skills/keypilot-model-adapter/`：给新模型/编程代理阅读的接入 Skill。它与 `desktop/skills/*/skill.json` 的运行时操作定义用途不同。
- `requirements/repro-windows-py312.lock`：本次复现使用的固定依赖版本。
- `scripts/build_share.py`：生成仅含源代码与文档的分享包和 SHA-256 清单。

```powershell
.\.venv\Scripts\python.exe scripts/build_share.py
```

产物是 `dist/KeyPilot-Repro-source.zip`。不包含 `.env`、API Key、私人录音、模型权重、会话记忆、原始聊天导出、实验工作目录或虚拟环境。发布包附 SHA-256，可从上面的 GitHub Releases 入口下载。

**语音包仅在本地使用，不上传或随项目分发。** 项目中的 `examples/voice-pack/voice.json` 只是无音频、无权重、不可直接发声的格式模板。其他人按规范在自己的电脑准备和导入自己的声音资源。

当前可复现的是应用、接口契约与导入流程。特定私人音色的听感和历史训练指标依赖未分发的数据、权重和机器，不能仅凭此源码包重现。兼容接口也不保证所有模型均能正确遵守结构化输出，需逐个测试。
